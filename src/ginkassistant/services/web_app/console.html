Quick start

Endpoints

POST /v1/chat/completionsChat. stream: true for word-by-word answers. Without model: Gink Crystal.
GET /v1/modelsModels you can use. gink-search searches the web and lists sources.
POST /v1/images/generations{"prompt"} → data[0].b64_json (PNG).
POST /v1/batches{"requests": [{"custom_id", "body"}], "name"}, up to 100. Then GET /v1/batches/{id}, /results (JSONL), /cancel.

Errors

401Missing, invalid or revoked key.
403The model needs Gink Pro.
422The request is malformed (the message says what to fix).
429Daily allowance or per-minute limit reached (see Retry-After).
502 / 503The AI service had a problem, or the server is waking up. Retry after a moment.
