Quick start

pip install openai

from openai import OpenAI
client = OpenAI(base_url="__BASE__", api_key="YOUR_GINK_KEY")

reply = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": "Write a haiku about Dakar"}],
)
print(reply.choices[0].message.content)
// npm install openai
import OpenAI from "openai";
const client = new OpenAI({ baseURL: "__BASE__", apiKey: process.env.GINK_KEY });

const reply = await client.chat.completions.create({
  model: "openai/gpt-oss-120b",
  messages: [{ role: "user", content: "Write a haiku about Dakar" }],
});
console.log(reply.choices[0].message.content);
curl __BASE__/chat/completions \
  -H "Authorization: Bearer $GINK_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "openai/gpt-oss-120b",
       "messages": [{"role": "user", "content": "Write a haiku about Dakar"}]}'

Endpoints

POST /v1/chat/completionsChat, with stream: true for word-by-word answers. Photos (image parts) need Gink Pro.
GET /v1/modelsThe models you can use right now: GPT-OSS and other fast models, plus Claude models with Gink Pro.
POST /v1/images/generations{"prompt": "..."} → data[0].b64_json (a PNG).

Limits

API calls share your account's daily allowance: Free 30 messages and 3 images a day, Gink Pro 500 messages and 50 images. Each key can also make up to 30 requests a minute. Over a limit, you get HTTP 429 with a message (and Retry-After for the per-minute limit).

If you ask for a model that's no longer available, Gink uses the best current one instead, so your code keeps working.
