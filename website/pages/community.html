Contribute code

Fork the repository, make your change, run the tests and open a pull request.

Before you open a pull request

pip install -r requirements-test.txt
python -m pytest tests

Every pull request runs the full test suite on GitHub automatically. Keep changes small and focused, and describe what they fix or add.
