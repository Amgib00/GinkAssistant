Build with Gink

Give your own app Gink’s answers, maps, voice and memory, or hand a task to a managed agent. It plans, works through up to 60 steps in a workspace that keeps its files, and tells you what changed.

  • Start building
  • API reference
  • Python SDK
  • JavaScript SDK
# pip install gink-ai
from gink import Client

client = Client()  # your GINK_API_KEY
run = client.interactions.create(
    input="Put the prices from example.org/prices in prices.md",
)
print(run.output_text)    # Wrote prices.md from the page.
print(run.files_changed)  # ['prices.md']
// npm install gink-ai
import Gink from "gink-ai";

const gink = new Gink();  // your GINK_API_KEY
const run = await gink.interactions.create({
  input: "Put the prices from example.org/prices in prices.md",
});
console.log(run.output_text, run.files_changed);
