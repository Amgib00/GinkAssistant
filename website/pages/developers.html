Get started

Sign in to the Developer Console with your Gink account and create a key. Keep it secret: put it in the GINK_API_KEY environment variable, or run gink login once and the SDK finds it.

pip install gink-ai     # the Python SDK and the gink command
npm install gink-ai     # the JavaScript SDK

Chat

Answers come with live information (weather, currency, the time where you are) and, with the search model, sources from the web.

from gink import Client

client = Client()
print(client.chat("What's the weather where I am?"))
print(client.search("When does the rainy season start in Nairobi?"))

Already using an OpenAI client? Point it at Gink:

curl {{API}}/v1/chat/completions \
  -H "Authorization: Bearer $GINK_API_KEY" -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Hello, Gink"}]}'

Agents

A managed agent takes a task, writes a plan, and works through up to 60 steps in a workspace that keeps its files between runs. It reads web pages, searches, and reads and writes files. If it stops with steps of its plan still open, it’s told to carry on.

run = client.interactions.create(
    input="Put the prices from example.org/prices in prices.md",
    max_steps=30,          # 1 to 60
)
print(run.plan)            # each step, "todo", "doing" or "done"
print(run.output_text, run.files_changed)

for event in client.interactions.create(input="Plan a week of meals", stream=True):
    print(event.type, event.data)       # every step as it happens

In JavaScript, await gink.interactions.create({ input, max_steps: 30 }); in a terminal, gink agent "task". Agents can also run on a schedule (client.schedules.create(task, every="daily", at="08:00")) and call a webhook when they finish.

Maps and places

Ask with gink_maps and answers about places end with a map block: a title, and each place’s name, coordinates and kind (museum, cafe, park and so on), ready to draw on your own map. Places by name or address come from OpenStreetMap, and a picture of a place comes from its Wikipedia article, like the photos on Gink’s map cards.

answer = client.chat("Three places to see art in Cape Town", gink_maps=True)
for m in client.maps(answer):
    print(m["title"], [(p["name"], p.get("category")) for p in m["places"]])

client.geo("Zeitz MOCAA, Cape Town")                  # name, address, lat, lon, map_url
client.place_photo("Zeitz MOCAA", -33.9085, 18.4228)  # image, title, page, credit (None when there's none)

In JavaScript, gink.placePhoto(name, lat, lon); in a terminal, gink map "Zeitz MOCAA, Cape Town" --photos.

Voice messages

Speech to text in any language (WAV, WebM, OGG, M4A, MP3, FLAC), and Gink’s natural voice back.

text = client.audio.transcribe("voice-note.m4a")
wav = client.audio.speech("Your table is booked for 8.")
open("reply.wav", "wb").write(wav)

In a terminal: gink transcribe voice-note.m4a and gink say "Hello" -o hello.wav.

Memory

The same memory as the app, with the same rules: sensitive topics only if you ask for them, and never passwords, codes or card numbers. How memory works.

client.memories.generate(messages)       # the lasting facts in a conversation, remembered
prompt = client.memories.import_prompt() # what to ask your other AI assistant
client.memories.import_text(its_answer)  # add what it remembered about you

Many requests at once

Up to 100 chat requests, answered in the background.

batch = client.batches.create(["Summarise chapter 1", "Summarise chapter 2"])
batch = client.batches.wait(batch["id"])
for r in client.batches.results(batch["id"]):
    print(r["custom_id"], r["response"]["choices"][0]["message"]["content"])

Location metadata

Requests carry your device’s time zone and language, so answers fit where you are. To send only your clock’s difference from UTC, use Client(location=False), new Gink({ location: false }), gink --no-location or GINK_LOCATION=off.

Limits

Your key uses your plan’s daily messages: 30 on Free, 500 with Gink Pro. A long agent task counts one message for every 10 steps. Photos and screen images need Gink Pro.
