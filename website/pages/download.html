Run Gink from source

For developers, on any computer with Python 3.10 or later.

git clone {{REPO}}.git
cd ginkassistant
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m ginkassistant

Setup notes for each platform are in the README.
