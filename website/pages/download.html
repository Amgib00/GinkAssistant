Download Gink

Gink is in beta. Get it for your computer, your phone, or use it in your browser.

Mac

Apple Silicon (M1 to M4): macOS 12 or later. Intel: macOS 11 or later. The first time, right-click Gink and choose Open.

Apple Silicon Intel

Android

Android 7 or later. Open the file on your phone and allow installing apps from this source. If your phone says the app isn't compatible (common on TECNO POP and itel phones), use the 32-bit version.

Download APK 32-bit

Web

Use Gink in any browser, with nothing to install.

Open Gink

Windows

Windows 10 or 11 (64-bit). If SmartScreen warns you, choose More info, then Run anyway.

Download installer

Linux

Ubuntu 24.04+ or Debian 13+ (64-bit). Install with: sudo apt install ./Gink-linux-amd64.deb

Run Gink from source

For developers, on any computer with Python 3.10 or later.

git clone {{REPO}}.git
cd ginkassistant
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m ginkassistant

Setup notes for each platform are in the README.
